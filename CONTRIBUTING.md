# Contributing

Edit the multi-page site under `site/`. The homepage is a segment directory; individual behaviors belong on their corresponding segment pages. Keep descriptions concise, impact flags readable, and source facts separate from added guidance.

Run the Node checks, source/link checks, and packaging script listed in README before committing. Review narrow and wide layouts, keyboard access, modal closing, filters, and behavior deep links. Do not add accounts, notes, analytics, or persistent visitor storage.

Use fictional examples in issue reports; include the segment or behavior ID, expected result, actual result, and browser details when relevant.
